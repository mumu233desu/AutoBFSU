# AutoBFSU 🏫🤖

`AutoBFSU` 是一款专门为北京外国语大学（BFSU）学生打造的轻量、高效的后台通知监控助手。

---

## ✨ 核心特性

- **多源抓取**：整合数字北外门户、Blackboard 平台与 CS 网站的通知及作业数据。
- **按需启用**：各抓取模块均可透过图形化界面独立开关，热重载即时生效。
- **AI 摘要**：接入大模型对长篇通知进行自动分类、精简提炼与相关度打分。
- **免扰机制**：基于本地持久化缓存，确保所有通知仅提醒一次。
- **安全免登**：使用 Windows DPAPI 硬件级加密账号凭证；维护持久化 Session 以绕过重复的双因子 (2FA) 验证。
- **托盘常驻**：提供后台守护模式与托盘菜单，支持一键开启开机自启。

---

## 🚀 快速上手 (普通用户)

直接解压分发包并运行：

> [!WARNING]
> **跨平台兼容性提示**：本项目目前主要在 Windows 环境下开发与深入测试。虽然底层代码和云端自动编译已原生支持生成 macOS 和 Linux 版本的执行文件，但在某些特定操作系统的系统托盘渲染 (`pystray`)、DPAPI 替代方案及系统调用上可能存在不稳定性。macOS 和 Linux 用户请自行测试和 Debug。
1. **双击运行** 目录下的 `AutoBFSU.exe`。
2. 首次运行将自动弹出**向导窗口**，引导您在图形化界面中填入账号凭证、运行参数及 AI 密钥。
3. 点击 **保存并应用设置**：敏感凭证将自动加密保护，程序随即转入后台常驻运行（常驻于 Windows 右下角蓝色铃铛托盘）。

## 💻 从源码运行 (开发者/进阶用户)

### 1. 安装依赖与环境
推荐使用包管理工具 `uv`：

```bash
uv sync
```

### 2. 配置与参数
支持图形化配置或手动配置：
* **图形化配置（推荐）**：直接启动程序，系统会自动唤醒参数设置 GUI。
* **手动配置**：复制 `.env.example` 并重命名为 `.env`，填入参数。手动填入的明文信息将在首次启动时被系统自动感知并安全转换为 DPAPI 密文。

### 3. 运行程序
可通过以下命令行参数启动：

```bash
# 1. 默认守护进程模式（推荐）：常驻系统托盘，后台周期性轮询
uv run main.py --daemon

# 2. 单次检测模式：立即运行一次通知与签到检查，然后退出
uv run main.py --once

# 3. 视觉效果测试：触发 Mock 测试通知，用来预览气泡窗口效果
uv run main.py --test-ui

# 4. 自定义周期：指定后台轮询检测的时间间隔（单位：分钟）
uv run main.py --daemon --interval 30
```

## 💡 使用小贴士

- **开机自启动**：
  * **一键开启（推荐）**：程序在后台运行时，直接右键点击桌面右下角托盘图标，勾选“开机自启动”即可自动完成注册表写入。
  * **手动配置（备用）**：若一键开启失败，可使用根目录下的 `autostart.bat` 脚本：
    1. 为项目根目录下的 `autostart.bat` 创建一个“快捷方式”。
    2. 按下 `Win + R` 键，输入 `shell:startup` 回车，打开系统的“启动”文件夹。
    3. 将刚创建好的“快捷方式”直接拖入该启动文件夹即可。
